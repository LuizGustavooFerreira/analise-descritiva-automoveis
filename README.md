# Análise Exploratória e Estatística Descritiva de Automóveis

Projeto de análise de dados desenvolvido com Python para explorar características de automóveis, investigar distribuições estatísticas e analisar relações entre variáveis.

## Objetivos

- Explorar e descrever as características do conjunto de dados.
- Investigar distribuições, valores ausentes e possíveis duplicidades.
- Analisar relações entre variáveis, como preço, potência e peso.
- Aplicar técnicas estatísticas e visualizar os resultados.

## Tecnologias

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Estatística descritiva
- Análise Exploratória de Dados (EDA)

## Etapas da análise

1. Carregamento e exploração dos dados.
2. Estatísticas descritivas e análise de distribuições.
3. Identificação de valores ausentes e duplicados.
4. Visualizações com histogramas, boxplots e gráficos de dispersão.
5. Análise de correlação de Pearson e Spearman.
6. Investigação de transformações de variáveis para reduzir assimetria.

## Principais resultados

A análise utiliza um conjunto de dados com 205 automóveis e 26 atributos.

Entre as investigações realizadas estão a distribuição dos preços, a relação entre características dos veículos e a comparação de correlações entre variáveis.

Os resultados detalhados e os gráficos estão disponíveis no notebook.

## Como acessar

Abra o arquivo `Trabalho_Analise_Descritiva_Completo.ipynb` neste repositório para consultar o código, as visualizações e os resultados.

Base de dados de automóveis. Consulte os arquivos de documentação incluídos no repositório para identificar a origem e as características das variáveis.
